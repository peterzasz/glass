# ROADEF/EURO 2018 Cutting Optimization Solver

C++ heuristic solver for the **ROADEF/EURO 2018 Cutting Optimization Challenge** proposed by Saint-Gobain.

The solver constructs feasible guillotine cutting patterns for defective glass plates while respecting item order, defect, cutting, and waste constraints. The project contains several heuristic approaches for item selection, rotation, placement, and lookahead evaluation.
